How to Play

  • W A S D or Arrows — Move
  • Shift — Sprint (uses stamina)
  • J — Pass to nearest teammate
  • K — Shoot (hold for power)
  • L — Tackle / Challenge
  • C — Change camera
  • Esc — Pause

On mobile: use the virtual joystick + action buttons.
